FetchXML Builder Web

Guía rápida para ejecutar la app web localmente y hacer pruebas de usuario.

Requisitos

  • Node.js 20 o superior.
  • npm incluido con Node.js.
  • Terminal ubicada en la raíz del repositorio.

Instalación

npm install

Ejecutar en modo local

npm run dev

Abre http://localhost:5173/ en el navegador.

Registra http://localhost:5173 como Redirect URI en Entra. La app usa un puerto fijo y no cambia a otro puerto si 5173 está ocupado.

Validación antes de entregar

npm test
npm run lint
npm run build

Flujos cubiertos

  • Editar, formatear, importar y exportar FetchXML.
  • Construir una query desde la vista Builder.
  • Revisar metadata de entidades y columnas.
  • Convertir a Power Automate, OData, C# y JavaScript.
  • Ejecutar contra datos mock y exportar resultados CSV/JSON.
